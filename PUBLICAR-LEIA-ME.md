# MESTRE CANTO ENSINO — pacote de publicação assistida

Contém o portal completo do protótipo v2.5 e o laboratório Modelo B com gap 4 px em `estudo-repeticoes/modelo-b-gap-4px.html`. **O leitor principal ainda não incorporou esse último microajuste.** As reproduções de páginas de partitura de terceiros foram excluídas deste pacote público, aguardando autorização de republicação.

Este portal ainda não contém o hinário integral nem as partituras completas. Não anunciar o contrário.

## Como publicar com segurança

O conector GitHub recusou a criação de uma branch (HTTP 403): nenhuma atualização foi enviada.

1. Acessar `https://github.com/siyayoacademy/mestrecantoensino` e criar uma branch de prévia a partir de `main` (`jaguar/portal-preview-v25`).
2. Extrair o ZIP e fazer upload na **raiz da nova branch** de todos os arquivos e pastas interiores, incluindo `index.html`, `assets/`, `data/` e as páginas internas; não enviar a pasta envoltória.
3. Conferir que não haja credenciais, arquivos privados ou outros documentos sem permissão de publicação; conferir direitos e autorização dos retratos/arte históricos.
4. Conferir o preview Cloudflare Pages, com páginas internas, imagens e laboratório.
5. Promover à `main` somente após homologação visual.

Sem acesso de escrita, não é possível garantir publicação automática até as 13h20.
